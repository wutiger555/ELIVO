Renders a Lucide outline icon (1.5–2px stroke look) tinted with currentColor; use for every glyph in ELIVO UI.
```jsx
<Icon name="file-text" size={16} />
<Icon name="git-compare" color="var(--warn)" />
```
- Names are Lucide kebab-case. Default 16px; use 14 in dense rows, 20 in headers.
- Never substitute emoji or robot/brain/mic/chat-bubble glyphs.
