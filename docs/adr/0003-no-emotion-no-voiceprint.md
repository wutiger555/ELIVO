# ADR-0003：不做情緒辨識；預設不建立聲紋；不以客戶資料訓練

- **狀態**：Accepted（2026-09-29）

## 背景
- EU AI Act Art. 5(1)(f)：自 2025/2/2 起禁止在職場／教育場域以生物特徵（含語音）推論情緒，罰則最高 €35M 或 7% 營收。
- Fireflies 兩件 BIPA 聲紋集體訴訟；GDPR 將用於識別的聲紋列為特殊類別。
- Otter（2026/8 動議駁回失敗）與 Granola（2026/7 被訴）案的核心爭點：供應商以錄音訓練模型 → 被視為第三方竊聽者。
- 品牌原則「Quiet / Human」與情緒評分相衝突。

## 決策
1. 任何市場版本皆不從語音 / 臉部推論情緒或對個人做情緒評分。
2. Speaker 處理預設僅 diarization（我 / 他人 / 說話者 A、B），不建立持久聲紋；未來若提供聲紋辨識，需逐人 opt-in 與書面同意。
3. 不以客戶內容訓練或微調共用模型（ToS / DPA 明文、次處理者 zero-retention）。
4. 行銷不得使用「隱形」「不被發現」等字眼。

## 後果
- ✅ 大幅降低訴訟與監管風險；成為信任差異化。
- ⚠️ 放棄「情緒 / 參與度分析」這類競品常見賣點（Read AI 等）。
- ⚠️ 模型改進需依賴取得明確同意的內部資料、合成資料與公開資料集。
